# Najm Vid 2.0

Native Arabic dark dashboard with a download library, quality preferences, and a separate quick-share sheet. Personal Android video downloader. Share a public video URL to Najm Vid, or paste a URL in the home screen. Android 10+; ARM64 (including Galaxy S25 Ultra) and x86_64.

## Cloud build

GitHub Actions builds on each push to `main`. Open **Actions → latest successful Build Najm Vid APK → Artifacts → Najm-Vid-APK**. Extract the ZIP and install `app-debug.apk` on your own Android device. No Android Studio or local build tools are required.

The workflow runs assembly, Android Lint, and unit tests. The APK is signed with the temporary debug key generated by that runner. A future build may require uninstalling the earlier app before installation; saved gallery files remain in shared storage.

## Interface and validation

- Three native screens: home, download library, and settings. A mint accent, custom vector icons, and a procedural illustration are drawn natively, with Arabic RTL layout and safe system/keyboard insets.
- Persistent history records actual queued, active, completed, failed, canceled, and interrupted tasks. It does not import gallery files downloaded by the older version.
- Quality preferences apply to quick shares. Manual paste always opens the preview. MP3 is available in the preview even for a single resolution.
- Active downloads can be canceled. Failed/interrupted downloads can be retried. Completed files can be opened or shared; removing a history item keeps the gallery file.
- Android instrumentation tests verify real launcher/navigation, preference persistence, invalid input, quick sharing, native downloading, MediaStore publication, MP3 conversion, and playable results. Screenshots of the actual dashboard are uploaded with the runtime test report.

## Behavior

- Extracts HTTP(S) links from shared captions; recognizes platform by hostname.
- Inspects actual formats, downloads automatically for zero/one detected video resolution, or offers a bottom sheet for multiple resolutions and MP3 audio. File sizes are estimates when source metadata exists.
- Prefers high quality MP4 video/audio streams and merges/remuxes through FFmpeg.
- Downloads run in a foreground service after the share dialog closes. Multiple requests queue within the running service. Progress and completion appear in notifications when allowed.
- Stages files in app cache; copies completed videos to `Movies/NV_[platform]` and MP3 to `Music/NV_[platform]` through MediaStore, publishing only after copying succeeds. No broad storage permission is requested.
- Updates yt-dlp from the upstream stable release at most daily; update failure falls back to the bundled runtime. Detailed download failures are available by tapping the failed download in the library.

Share ranking belongs to Android/One UI; the app cannot force first position. Pinning depends on the device's sharesheet. Watermark-free output is available only when the source exposes such a stream; the app does not remove embedded watermarks. Some public URLs need authentication or are blocked by a platform. DRM-protected media is unsupported. Download only media you are permitted to save.

Foreground service operation is not a durable download queue: force-stop, reboot, or system process termination may interrupt it; share the URL again to retry. Quality analysis is canceled when its activity closes. There is no server, login-cookie importer, or guaranteed support for every platform.
